# Data

`customers.csv` has one row per customer, built by `scripts/build_dataset.py` from the **Online Retail** dataset:
Daqing Chen, UCI Machine Learning Repository, [doi:10.24432/C5BW33](https://doi.org/10.24432/C5BW33), CC BY 4.0.

The raw file has 541,909 invoice lines from a UK online store, December 2010 to December 2011. Lines without a customer ID,
returns and zero-price lines are removed, leaving 4,338 customers. Customer IDs are the anonymous numbers from the source.
